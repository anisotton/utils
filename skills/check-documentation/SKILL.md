## O que faço

- Buscar documentação oficial de tecnologias e frameworks do projeto
- Localizar exemplos de uso e boas práticas
- Verificar versões e compatibilidades de bibliotecas
- Consultar guias de integração e configuração
- Fornecer referências de API e métodos disponíveis

## Quando usar

Use quando você precisa verificar como usar uma tecnologia específica, entender melhor um framework, consultar a API de uma biblioteca ou buscar boas práticas recomendadas pela documentação oficial.
